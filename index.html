How I work

The whole stack, or it isn't shipped.

Most portfolios stop where the hard part starts. These are the layers I actually own on every project.

Research & product definition

Finding the real problem before designing a screen for it. Shiftsly came from watching London cleaning managers run everything on WhatsApp.

Interface & design systems

Tokens, type scales, dark-first palettes, and density rules tuned per surface — built to be implemented, not just admired.

Frontend implementation

Next.js, TypeScript, React and Tailwind. I build my own designs, so nothing gets lost between Figma and the browser.

Backend & data

PostgreSQL, Prisma, REST integrations and scheduled jobs. The data model is a design decision as much as the layout is.

Payments & subscriptions

Live Stripe and Hubla integrations — checkout, webhooks, subscription lifecycle, account states, cancellation. The flow most designers never touch.

Production operations

Deploys, cron scheduling, monitoring and incident response. I've debugged real outages that hit paying customers, and shipped the alerting so they don't repeat.
